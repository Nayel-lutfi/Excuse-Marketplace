# Excuse Marketplace

A deliberately useless web experience that assigns fictional market rates to excuses.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints, usually `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## What is included

- Live fictional market rates
- Search/check-rate flow
- Dynamic price movement
- Price history chart
- Trending/rising/falling lists
- Market news
- Random market events
- Categories
- Community submission
- Responsive desktop/mobile website
- No API key required
- No backend required

The price system is intentionally fictional and runs entirely in the browser.
